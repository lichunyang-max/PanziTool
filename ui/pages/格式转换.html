常见问题

支持哪些图片格式互转？

支持 JPG、PNG、WebP、GIF、BMP 五种常见格式之间的相互转换。您可以从任意一种格式转换为其他四种格式，例如将 PNG 转为 JPG 以减小文件体积，或将 JPG 转为 WebP 以获得更好的网页加载性能。所有转换均在浏览器本地通过 Canvas API 完成。

转换后图片质量会下降吗？

取决于目标格式和压缩设置。JPG 和 WebP 为有损格式，可通过质量滑块控制压缩率（1% - 100%），推荐设置在 80%-95% 之间以平衡质量与体积。

PNG 和 GIF：无损格式，转换后不会损失画质，但文件体积可能较大。

BMP：无压缩位图，画质完全保留，但文件体积最大。

WebP：同时支持有损和无损压缩，是现代网页的最佳选择。

为什么转JPG后背景变白了？

JPG 格式不支持透明通道（Alpha 通道），转换时透明区域会填充为背景色（默认白色）。

如果您希望保留透明背景，请将目标格式选择为 PNG、WebP 或 GIF，这三种格式均支持透明通道。

如需自定义背景色，可在"调整选项"中通过颜色选择器设置任意颜色，透明区域将填充为您选择的颜色。

可以批量转换吗？

可以。支持一次上传多张图片，统一设置目标格式和质量，批量转换并分别下载。

上传时可在文件选择对话框中按住 Ctrl（Windows）或 Cmd（Mac）多选文件，也可直接拖拽多个文件到上传区域。转换完成后，可点击"全部下载"依次下载所有转换后的图片，或点击每个文件右侧的下载按钮单独下载。

WebP格式有什么优势？

WebP 是 Google 推出的现代图片格式，相比 JPG 体积更小，同时支持有损/无损压缩和透明通道，是目前网页图片的最优选择。

体积更小：同等画质下，WebP 比 JPG 小 25%-35%，能显著提升网页加载速度。

功能更全：支持透明通道（替代 PNG）和动画（替代 GIF），一种格式满足多种需求。

兼容性好：所有现代浏览器（Chrome、Firefox、Edge、Safari 14+）均已支持。

图片会上传到服务器吗？

不会。所有格式转换完全在浏览器本地通过 Canvas API 完成，图片数据不会离开您的设备。

技术上，图片通过浏览器的 File API 读取为 DataURL，然后使用 Canvas 重新绘制并通过 canvas.toBlob() 以目标格式编码。整个过程中数据不会通过网络发送到任何服务器。

因此，即使是敏感图片，也可以放心使用本工具进行格式转换。
