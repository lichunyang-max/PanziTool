常见问题

支持哪些图片格式？

支持 JPG、PNG、GIF、WebP、BMP 等常见图片格式，最大文件大小为 20MB。如果您的图片超过此限制，建议先使用图片压缩工具进行压缩。所有格式均可裁剪并导出为 PNG、JPEG 或 WebP 格式。

裁剪后图片质量会下降吗？

裁剪操作本身不会降低图片质量。裁剪只是选取原图的一个区域，不会对像素进行缩放或压缩。

PNG 格式：无损保存，适合需要最高质量的场景，但文件体积较大。

JPEG 格式：有损压缩，可通过质量滑块调整压缩率（0.1 - 1.0），适合照片类图片。

WebP 格式：兼顾质量与体积，现代浏览器均支持，推荐用于网页场景。

图片会上传到服务器吗？

不会。所有图片处理完全在浏览器本地完成，图片数据不会离开您的设备。

技术上，图片通过浏览器的 File API 读取为 DataURL，然后使用 Canvas API 进行裁剪、旋转、翻转等操作。整个过程中数据不会通过网络发送到任何服务器。

因此，即使是敏感图片，也可以放心使用本工具进行处理。

如何使用预设比例裁剪？

在裁剪比例区域选择所需比例（如 1:1、16:9、4:3 等），裁剪框将自动调整为对应比例。

选择比例后，拖拽裁剪框的边角手柄进行调整时，裁剪框会始终保持所选比例不变。选择"自由"比例则可无约束地任意调整裁剪框大小。

常见用途：1:1 适合头像、社交媒体方图；16:9 适合视频封面、横幅；9:16 适合手机壁纸、竖版短视频封面。

可以旋转和翻转图片吗？

可以。工具支持以下操作：

向左旋转 90°：将图片逆时针旋转 90 度。

向右旋转 90°：将图片顺时针旋转 90 度。

水平翻转：沿垂直轴左右镜像翻转。

垂直翻转：沿水平轴上下镜像翻转。

旋转和翻转操作会即时生效，裁剪框会自动适配新的图片方向。可以连续多次操作实现 180°、270° 等旋转效果。

裁剪框如何操作？

移动裁剪框：鼠标按住裁剪框中间区域拖拽，可移动裁剪框位置。

调整大小：裁剪框四周有 8 个调整手柄（4 个角 + 4 条边中点），拖拽手柄可改变裁剪框大小。

角手柄：拖拽四个角的手柄可同时调整宽度和高度（自由模式下），或按比例调整（锁定比例模式下）。

边手柄：拖拽四条边中点的手柄仅调整对应方向的尺寸（自由模式下），锁定比例时会联动调整以保持比例。

裁剪框始终被限制在图片范围内，不会超出边界。实时尺寸信息显示在画布左上角和右侧参数面板中。
