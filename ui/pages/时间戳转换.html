常见问题

什么是 Unix 时间戳？

Unix 时间戳是从协调世界时（UTC）1970年1月1日00:00:00开始所经过的秒数，不考虑闰秒。它是计算机系统中表示时间的常用方式，广泛应用于各种编程语言和数据库中。

时间戳的秒和毫秒有什么区别？

秒级时间戳是以秒为单位的整数（10位数字，如 1698765432），而毫秒级时间戳是以毫秒为单位的整数（13位数字，如 1698765432000）。1 秒 = 1000 毫秒。JavaScript 的 Date.now() 默认返回毫秒级，而 Unix 系统调用通常返回秒级。转换时只需乘以或除以 1000 即可。

如何在不同编程语言中获取当前时间戳？
JavaScript
// 毫秒级
const ms = Date.now();
// 秒级
const s = Math.floor(Date.now() / 1000);
Python
import time
# 秒级（浮点数）
s = time.time()
# 毫秒级
ms = int(time.time() * 1000)
Java
// 毫秒级
long ms = System.currentTimeMillis();
// 秒级
long s = System.currentTimeMillis() / 1000;
Go
import "time"
// 毫秒级
ms := time.Now().UnixMilli()
// 秒级
s := time.Now().Unix()
为什么有时区差异？

Unix 时间戳本身是基于 UTC 的，与时区无关。但在将时间戳转换为人类可读的日期时间时，需要指定时区才能得到正确的本地时间。例如，同一个时间戳 1698765432 在北京时间（UTC+8）显示为 2023-10-31 17:17:12，而在纽约时间（UTC-5）则显示为 2023-10-31 04:17:12。使用上方的时区选择器可以在不同时区间切换查看。
