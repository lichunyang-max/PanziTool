常见问题

URL编码和URI编码有什么区别？

URL（统一资源定位符）是 URI（统一资源标识符）的子集，因此 URL 编码本质上是 URI 编码的一种应用。RFC 3986 定义了 URI 中允许出现的字符集，以及哪些字符需要被百分号编码（percent-encoding）。日常所说的"URL 编码"通常就是指把不符合 URI 规范的字符（如中文、空格、特殊符号）转换为 %XX 形式的过程。

encodeURI 和 encodeURIComponent 有什么区别？

encodeURI 用于编码完整的 URL，它会保留 URL 中具有结构意义的特殊字符，如 / : ? = & # @ 等，仅编码非 ASCII 字符和空白等。适合对整个 URL 进行编码。

encodeURIComponent 用于编码 URL 的某个组成部分（如查询参数的键值），它会编码几乎所有特殊字符，包括 / : ? = & # 等，避免这些字符破坏 URL 结构。适合对查询参数值进行编码。

简单规则：编码完整 URL 用 encodeURI；编码查询参数值用 encodeURIComponent。本工具可在"编码选项"中切换。

空格应该编码为 %20 还是 +？

两种方式都合法，但适用场景不同：

%20 是 RFC 3986 标准的空格编码方式，适用于 URL 的任何部分（路径、查询字符串等），由 encodeURI / encodeURIComponent 默认使用。

+ 是 application/x-www-form-urlencoded（表单提交）MIME 类型中规定的空格编码方式，主要用于查询字符串中的表单参数。JavaScript 的 encodeURIComponent 不会把空格编码为 +，需要手动替换。

建议：URL 路径中的空格用 %20；表单查询参数中的空格可以用 +。本工具提供切换选项。

如何在不同编程语言中进行URL编码？
JavaScript
// 编码完整 URL
const encoded = encodeURI("https://example.com/搜索?q=中文");
// 编码查询参数值
const param = encodeURIComponent("中文 测试");
// 解码
const decoded = decodeURIComponent("https%3A%2F%2Fexample.com");
Python
from urllib.parse import quote, quote_plus, unquote

# 编码（默认 encodeURI 行为，safe 默认为 /）
encoded = quote("https://example.com/搜索?q=中文")
# 编码所有特殊字符（safe='' 相当于 encodeURIComponent）
encoded = quote("中文 测试", safe='')
# 空格编码为 +
encoded = quote_plus("中文 测试")
# 解码
decoded = unquote("https%3A%2F%2Fexample.com")
Java
import java.net.URLEncoder;
import java.net.URLDecoder;
import java.nio.charset.StandardCharsets;

// 编码（空格编码为 +）
String encoded = URLEncoder.encode("中文 测试", StandardCharsets.UTF_8);
// 解码
String decoded = URLDecoder.decode("%E4%B8%AD%E6%96%87", StandardCharsets.UTF_8);
Go
import "net/url"

// 编码查询参数值
encoded := url.QueryEscape("中文 测试")
// 解码
decoded, err := url.QueryUnescape("%E4%B8%AD%E6%96%87")
// 编码路径（空格编码为 %20）
pathEncoded := url.PathEscape("中文 测试")
为什么中文被编码为 %E4%B8%80 这样的格式？

URL 中只能包含 ASCII 字符，非 ASCII 字符（如中文）需要先转换为字节序列，再对每个字节进行百分号编码。现代 URL 编码统一使用 UTF-8 作为字符编码。

以"中"字为例：UTF-8 编码后占 3 个字节 E4 B8 AD，因此 URL 编码结果为 %E4%B8%AD。"文"字编码后为 %E6%96%87，所以"中文"完整的 URL 编码就是 %E4%B8%AD%E6%96%87。

一个中文字符通常对应 3 个 %XX 编码（UTF-8 下），这就是为什么中文 URL 编码后会变得很长。
