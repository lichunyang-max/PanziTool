常见问题

什么是哈希函数？

哈希函数是一种将任意长度的输入数据映射为固定长度输出的单向函数。它具有以下特性：相同的输入始终产生相同的输出（确定性）；输入的微小变化会导致输出的巨大变化（雪崩效应）；从输出几乎不可能反推输入（单向性）；以及找到两个不同输入产生相同输出在计算上不可行（抗碰撞）。常见的哈希算法包括 MD5、SHA-1、SHA-256 等，广泛用于数据完整性校验、密码存储、数字签名等场景。

MD5 和 SHA-256 有什么区别？

MD5 和 SHA-256 是两种常见的哈希算法，主要区别如下：

输出长度：MD5 输出 128 位（32 个十六进制字符），SHA-256 输出 256 位（64 个十六进制字符）。

安全性：MD5 已被证明存在严重的碰撞漏洞，不再适合安全场景；SHA-256 目前仍被认为是安全的，广泛用于数字证书、区块链等。

性能：MD5 计算速度更快，适合非安全场景的快速校验；SHA-256 计算稍慢但更安全。

推荐用途：MD5 仅推荐用于文件校验、缓存键等非安全场景；SHA-256 推荐用于所有需要安全性的场景。

哈希值可以反向解密吗？

哈希是单向的，理论上无法从哈希值反推出原始输入。这与加密不同——加密是可逆的（用密钥解密），而哈希没有"解密"过程。

但是，对于弱哈希算法（如 MD5）或常见输入（如简单密码），攻击者可以通过彩虹表（预计算的哈希对照表）或暴力破解来"猜"出原始输入。这就是为什么存储密码时应使用加盐（salt）的慢哈希函数（如 bcrypt、Argon2），而非直接使用 MD5 或 SHA-256。

简而言之：哈希不能"解密"，但可以通过碰撞或穷举"破解"弱输入。因此请勿将哈希作为加密手段使用。

为什么相同的输入会产生不同的哈希值？

理论上，相同的输入必然产生相同的哈希值。如果出现不同结果，通常是由于以下原因：

编码差异：文本在计算前需转换为字节。UTF-8、GBK、UTF-16 等编码方式对同一文本会得到不同的字节序列，进而产生不同的哈希。本工具统一使用 UTF-8 编码。

空白字符差异：首尾空格、换行符（\n 与 \r\n）、制表符等不可见字符的差异都会导致哈希不同。

大小写差异：哈希计算区分大小写，"Hello" 与 "hello" 的哈希值不同。

排查方法：将两段文本转换为十六进制字节逐字节对比，通常能发现隐藏的差异。

如何在不同编程语言中计算哈希？
JavaScript（SubtleCrypto API）
// SHA-256（异步，返回 Promise）
async function sha256(text) {
  const data = new TextEncoder().encode(text);
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
console.log(await sha256('Hello'));
// "185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969"

// 注意：SubtleCrypto 不支持 MD5，需使用第三方库（如 spark-md5）
Python（hashlib）
import hashlib

# SHA-256
print(hashlib.sha256("Hello".encode("utf-8")).hexdigest())
# 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969

# MD5
print(hashlib.md5("Hello".encode("utf-8")).hexdigest())
# 8b1a9953c4611296a827abf8c47804d7

# 文件哈希（推荐分块读取大文件）
h = hashlib.sha256()
with open("file.bin", "rb") as f:
    for chunk in iter(lambda: f.read(8192), b""):
        h.update(chunk)
print(h.hexdigest())
Java（MessageDigest）
import java.security.MessageDigest;
import java.nio.charset.StandardCharsets;

MessageDigest md = MessageDigest.getInstance("SHA-256");
byte[] hash = md.digest("Hello".getBytes(StandardCharsets.UTF_8));

// 转十六进制字符串
StringBuilder sb = new StringBuilder();
for (byte b : hash) {
    sb.append(String.format("%02x", b));
}
System.out.println(sb.toString());
// 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
Go（crypto/sha256）
package main

import (
    "crypto/sha256"
    "encoding/hex"
    "fmt"
)

func main() {
    h := sha256.New()
    h.Write([]byte("Hello"))
    fmt.Println(hex.EncodeToString(h.Sum(nil)))
    // 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
}
文件哈希计算会上传我的文件吗？

不会。本工具的所有计算完全在浏览器本地完成，文件不会被上传到任何服务器。您可以在断网状态下使用文件哈希功能，它依然能正常工作。

技术上，文件通过浏览器的 File API 读取为 ArrayBuffer，然后使用 crypto.subtle.digest 在本地计算哈希值。整个过程中数据不会离开您的设备。

因此，即使是敏感文件，也可以放心使用本工具计算哈希值。
