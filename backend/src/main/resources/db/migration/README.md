# Flyway 迁移脚本目录

本目录用于存放 Flyway 数据库迁移脚本（`V{version}__{description}.sql`）。

## 迁移脚本清单（Task 3）

| 版本 | 文件 | 说明 |
|------|------|------|
| V1 | `V1__create_tools_table.sql` | 工具元数据表（slug 唯一索引、category+use_count 复合索引） |
| V2 | `V2__create_tool_event_logs_table.sql` | 原始事件日志表（tool_id+created_at、anon_id+created_at 索引） |
| V3 | `V3__create_tool_event_daily_table.sql` | 按天聚合统计表（tool_id+event_date+event_type 唯一约束） |
| V4 | `V4__create_tool_likes_table.sql` | 点赞记录表（tool_id+anon_id 唯一约束） |
| V5 | `V5__create_site_visitor_daily_table.sql` | 站点日统计表（stat_date 唯一索引） |

## 兼容性说明

迁移脚本同时兼容 PostgreSQL（生产 dev/prod profile）和 H2（默认 profile，MODE=PostgreSQL）：

- 主键使用 `BIGINT GENERATED BY DEFAULT AS IDENTITY`（PostgreSQL 10+ 与 H2 均支持）
- 使用标准 SQL 类型：`BIGINT`、`VARCHAR`、`BOOLEAN`、`TIMESTAMP`、`DATE`
- 避免 PostgreSQL 特有语法（`SERIAL`、`RETURNING`、`ON CONFLICT` 等）
- H2 URL 已配置 `DATABASE_TO_LOWER=TRUE`，使标识符折叠为小写，与 PostgreSQL 行为一致
